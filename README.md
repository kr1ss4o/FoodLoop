# FoodLoop

The website is hosted using SmarterASP.net on this address: https://foodloop.store
The connection is secured by CloudFlare's free SSL sertificate as well as the SSL certificated issued by SmarterASP.

FoodLoop aims to fight with the global problem - Wasting food and food supplies.
FoodLoop present a new and interactive way for restaurants and local food businesses to sell
their extra food which they could not sell throught the work day/s. Therefore, the food does not go
to waste and it is far more accessible for every customer because of its lower price.

The website was built using ASP.NET Core.
